A single believable excuse for the make.fun "The Excuse That Almost Works" bounty: the text a gamer sends the boss to skip work during GTA 6 launch week.

## The entry

> Lift's out and my flat's on the 14th floor, so I'll work from home before my knees file a complaint.

## How to run

```sh
python3 main.py
```

This writes the line to `entry.txt` in the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`), with a trailing newline.
